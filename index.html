SSPDF FAQ / User Guide

SSPDF के उपलब्ध tools और features को आसानी से समझने के लिए यह संपूर्ण हिन्दी guide है।

1. PDF खोलना, नया PDF और Workspace
  • Open PDF से PDF चुनें या Drag & Drop करें।
  • New PDF से blank PDF शुरू करें।
  • ऊपर Save, Save As और Export PDF से अपना काम सुरक्षित/download करें।
2. Pages और Thumbnails
  • Pages panel में thumbnails से page चुनें।
  • Add PDF या Add Blank Page से page जोड़ें।
  • Rotate Left/Right, Duplicate और Delete से page manage करें।
  • Thumbnail को लगातार drag करते हुए ऊपर/नीचे ले जाकर page order बदलें।
3. Text
  • Text tool चुनकर PDF पर tap/click करके लिखें।
  • Text box को Select करके move करें; double tap/click से edit करें।
  • Text box text के अनुसार auto-fit होता है और जरूरत के अनुसार resize/move किया जा सकता है।
  • Properties में font, size, bold, italic, color और alignment बदल सकते हैं। Hindi/Devanagari के लिए उपयुक्त font भी उपलब्ध है।
4. Highlight, Draw और Shapes
  • Highlight से text area highlight करें।
  • Draw, Line, Arrow और Ellipse से annotations बनाएँ।
  • Whiteout से किसी हिस्से को छिपाएँ और Checkmark से ✓ लगाएँ।
  • Properties में color, thickness और opacity जैसी settings बदलें।
5. Image और Signature
  • Image से image insert करें; Select tool से move और resize करें।
  • Selected image के लिए Properties → Crop Selected Image खोलें।
  • Crop Image में Percent (%) या Pixels (px) चुनें और Top/Right/Bottom/Left values बदलते समय live preview देखें।
  • Signature में Draw, Type या Upload से signature जोड़ें।
6. Crop PDF
  • Crop PDF में Top, Right, Bottom और Left से हटाया जाने वाला हिस्सा दर्ज करें।
  • Unit mm, cm या inch में चुन सकते हैं।
  • Values बदलते समय PDF का live crop preview दिखता है और crop area की size भी दिखाई जाती है।
  • Current page या All Pages पर crop लागू किया जा सकता है।
7. Merge PDF
  • Merge खोलें → PDFs जोड़ें → order तय करें → Merge & Export दबाएँ।
  • PDFs browser में client-side process होकर download होती हैं।
8. Split PDF
  • Split में All, Current, Range या Selected pages चुनकर अलग PDF/ZIP export करें।
9. Image → PDF
  • JPG, PNG या WEBP images चुनें।
  • Image list में drag करके order बदलें।
  • Page size, orientation, margin और fit चुनकर Create PDF & Download दबाएँ।
10. PDF → Image
  • All, Current या Range pages चुनें।
  • PNG/JPG/WebP और resolution चुनें। Multiple pages के लिए ZIP download हो सकता है।
11. OCR
  • OCR में English, Hindi या English + Hindi चुनें।
  • OCR searchable/selectable text बनाने का प्रयास करता है।
  • Extracted text को copy या TXT के रूप में download किया जा सकता है।
12. Compress
  • Low / Medium / High compression level चुनें।
  • जरूरत होने पर selectable/copyable text option का उपयोग करें।
13. Scan
  • Scan से mobile camera या image files द्वारा pages जोड़ें।
  • Pages का क्रम देखें और Create PDF & Open से PDF बनाकर SSPDF में खोलें।
14. Enhance
  • Enhance में Auto Enhance, Original, Grayscale, Black & White, High Contrast और Sharpen जैसे modes उपलब्ध हैं।
  • Brightness और Contrast भी adjust कर सकते हैं।
  • Preview देखकर Current, Range या All pages पर enhancement लागू करें।
15. Watermark
  • Watermark से text watermark जोड़ें।
  • Font size, opacity, color और rotation angle सेट करें।
  • Watermark को Select tool से move और resize भी किया जा सकता है।
16. Search, Undo/Redo और Tools
  • Search या Ctrl+F से PDF text खोजें और results पर जाएँ।
  • Undo / Redo से actions वापस या फिर लागू करें।
  • Hand tool से page को pan/scroll करें और mobile पर pinch-zoom का उपयोग करें।
17. Properties Panel
  • Select किए गए object की settings Properties panel में मिलती हैं।
  • Text, image, signature, shapes और watermark के लिए उपलब्ध settings वहीं से बदलें।
  • Image select होने पर Crop Selected Image भी उपलब्ध होता है।
18. Auto Recovery और Privacy
  • Auto Recovery recent local work को browser के local IndexedDB में अस्थायी रूप से रखता है ताकि unexpected reload के बाद recovery का विकल्प मिल सके।
  • SSPDF के document operations browser में client-side होते हैं; documents को SSPDF के किसी remote backend पर upload करने की जरूरत नहीं होती।
19. Mobile उपयोग
  • ऊपर utility row को horizontally scroll करके सभी tools तक पहुँचें।
  • Pages और Properties panels को mobile buttons से खोलें/बंद करें।
  • Long dialogs में अंदर का content scroll किया जा सकता है, इसलिए buttons screen से बाहर नहीं जाने चाहिए।

A complete English guide to the tools and features currently available in SSPDF.

1. Open PDF, New PDF and Workspace
  • Use Open PDF or drag and drop a PDF.
  • Use New PDF to start a blank PDF.
  • Use Save, Save As and Export PDF to download your work.
2. Pages and Thumbnails
  • Use the Pages panel to select pages from thumbnails.
  • Use Add PDF or Add Blank Page to add pages.
  • Rotate, Duplicate and Delete pages as needed.
  • Drag a thumbnail continuously up or down to change the page order.
3. Text
  • Select Text and click/tap on the PDF to type.
  • Select a text box to move it; double-click/tap to edit.
  • The text box auto-fits to its content and can be moved/resized as needed.
  • Use Properties for font, size, bold, italic, color and alignment. Suitable Devanagari/Hindi font support is included.
4. Highlight, Draw and Shapes
  • Use Highlight to mark an area.
  • Use Draw, Line, Arrow and Ellipse for annotations.
  • Use Whiteout to cover an area and Checkmark to add ✓.
  • Use Properties to change color, thickness and opacity where supported.
5. Image and Signature
  • Insert an image with Image; move and resize it with Select.
  • For a selected image, open Properties → Crop Selected Image.
  • Crop Image supports Percent (%) or Pixels (px), with a live preview while Top/Right/Bottom/Left values change.
  • Signature supports Draw, Type and Upload.
6. Crop PDF
  • Use Top, Right, Bottom and Left to define the amount removed from each edge.
  • Choose mm, cm or inch as the unit.
  • The PDF has a live crop preview and the resulting crop area size is shown while you edit the values.
  • Apply the crop to the current page or all pages.
7. Merge PDF
  • Open Merge → add PDFs → arrange their order → press Merge & Export.
  • The PDFs are processed client-side in the browser and downloaded.
8. Split PDF
  • Use Split to export All, Current, Range or Selected pages.
9. Image → PDF
  • Select JPG, PNG or WEBP images.
  • Drag the image list to change order.
  • Choose page size, orientation, margin and fit, then press Create PDF & Download.
10. PDF → Image
  • Choose All, Current or Range pages.
  • Select PNG/JPG/WebP and the resolution. Multiple pages can be downloaded as a ZIP.
11. OCR
  • Choose English, Hindi or English + Hindi.
  • OCR attempts to create searchable/selectable text.
  • Extracted text can also be copied or downloaded as TXT.
12. Compress
  • Choose Low / Medium / High compression.
  • Use the selectable/copyable text option when required.
13. Scan
  • Use Scan with the mobile camera or image files to add pages.
  • Review the page order and press Create PDF & Open to create and open the PDF in SSPDF.
14. Enhance
  • Enhance provides Auto Enhance, Original, Grayscale, Black & White, High Contrast and Sharpen modes.
  • Brightness and Contrast can also be adjusted.
  • Preview the result and apply it to the Current page, a Range or All pages.
15. Watermark
  • Use Watermark to add text watermarks.
  • Set font size, opacity, color and rotation angle.
  • Move and resize the watermark with the Select tool.
16. Search, Undo/Redo and Tools
  • Use Search or Ctrl+F to find text and navigate results.
  • Use Undo / Redo to reverse or restore actions.
  • Use Hand to pan/scroll; on mobile, pinch with two fingers to zoom.
17. Properties Panel
  • Select an object to access its settings in Properties.
  • Use Properties for text, images, signatures, shapes and watermarks.
  • For selected images, Crop Selected Image is also available.
18. Auto Recovery and Privacy
  • Auto Recovery temporarily keeps recent local work in the browser's IndexedDB so recovery can be offered after an unexpected reload.
  • SSPDF's document operations are client-side in the browser; documents do not need to be uploaded to an SSPDF remote backend.
19. Mobile Use
  • Horizontally scroll the utility row to reach all tools.
  • Use the mobile Pages and Properties buttons to open/close side panels.
  • Long dialogs scroll internally so their controls remain accessible.
